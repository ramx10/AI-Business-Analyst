# AI Business Analyst

An AI-powered business analytics platform that automatically understands datasets, cleans data, analyzes business insights, and generates dashboards using multiple AI agents.

## Features
- Automated data cleaning
- Business understanding agent
- Analytics agent
- Schema detection
- Dashboard generation
- PostgreSQL support
- Large dataset handling (50k+ rows)
- Multi-agent workflow using CrewAI

## Tech Stack
- Python
- LangChain
- CrewAI
- Gemini API
- Polars
- DuckDB
- PostgreSQL
- Streamlit
- Pandas
- Plotly
